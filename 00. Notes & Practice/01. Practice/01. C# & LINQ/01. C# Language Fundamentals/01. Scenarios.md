## Answers

### Question 1

Add `using System;` at the top. `Console` lives in `System`. This repo disables implicit global usings so beginners see every dependency explicitly (ch.01 Hello World).

### Question 2

`Console.Write("Status: ")` then `Console.WriteLine("Online")`. Write keeps the cursor on the line; WriteLine completes the row (ch.03 Input & Output).

### Question 3

Binary floating-point cannot represent all decimal fractions exactly; use `decimal` for monetary values (ch.02 Data Types).

### Question 4

Integer division `999/4` truncates to 249 before cast. Use `(decimal)999 / 4` or `999m / 4` (ch.04 Operators, ch.05 Casting).

### Question 5

Read string → `TryParse` to int → `full = total / 12`, `loose = total % 12` → interpolate summary line. Money fields would use `decimal` (ch.03, ch.04, ch.02).

### Question 6

`TryParse` + branch for expected bad input; try/catch for exceptional failures (ch.03, ch.05, ch.10).

### Question 7

No — CS0165 unassigned local `score` on odd seconds (ch.02 scope / definite assignment).

### Question 8

Yes — `==` compares character content for strings, not reference identity (ch.04 comparison preview, ch.08 Strings).

### Question 9

`attempts` stays 0; `&&` short-circuits when left is false (ch.04 logical).

### Question 10

After `++n`: n=6, a=6. After `n++`: b=6, n=7. Final n=7, a=6, b=6 (ch.04 increment).

### Question 11

70 and 90. Multiplication before addition unless parentheses override (ch.04 precedence).

### Question 12

`??` for coalesce in expression; `??=` to assign default only when variable is null (ch.04 null-coalescing).

### Question 13

Grant: `flags = flags | write`. Test admin: `(flags & admin) != 0` (ch.04 bitwise).

### Question 14

If null/whitespace → return subtotal. `TryParse` coupon; on failure return subtotal; else subtract `subtotal * percent / 100` with decimal math (ch.05, ch.04).

### Question 15

Release: `stockOk && paid && !hold`. Express: `weight > 0 && weight <= 20 && !hold` (ch.04, ch.07).

### Question 16

Loop: sum `price[i]*qty[i]`; track max qty index from start; average `revenue/units` if units>0 else 0 (ch.09 Arrays/Loops, ch.06 Methods).

### Question 17

Count where completed[i]; average durations of completed; aggregate minutes by doctor id on completed rows, max sum, tie lower id (ch.06, ch.07, ch.09 Loops).

### Question 18

Fixed array OK when 50 is a hard cap; preview List for growth in Generics module (ch.09 Arrays).

### Question 19

Swallows bugs, no diagnostics, hides stack; validate input in small methods; catch specific exceptions at UI boundary (ch.10).

### Question 20

Return false for routine "cannot add to cart"; throw when transaction must abort and callers must not ignore (ch.10 custom exceptions).

### Question 21

Composite format or interpolation with `:C` on decimals (ch.03, ch.08).

### Question 22

Trim → uppercase invariant → replace spaces with `-` (ch.08 Strings, ch.06 Methods).

### Question 23

`TryParse` for optional; `Parse` or TryParse with guard for required; mention `Convert` for widening (ch.05).

### Question 24

`continue` skips rest of inner iteration; `break` exits inner loop entirely (ch.09 Loops).

### Question 25

Switch when comparing same variable to many constants; if/else fine for few branches (ch.07 Control Flow).
