## Build projects

| Problem | Domain | Difficulty |
|---------|--------|------------|
| [AlumniRosterSerializer](Problems/AlumniRosterSerializer/) | JSON/XML alumni roster | Medium |
| [ProductExportScanner](Problems/ProductExportScanner/) | Attribute-driven export | Medium |
| [CustomerImportValidator](Problems/CustomerImportValidator/) | Import regex validation | Medium |
| [FlexibleFeedAdapter](Problems/FlexibleFeedAdapter/) | Dynamic feed adapter | Medium |
| [WarehouseOrderRouter](Problems/WarehouseOrderRouter/) | C# 7 order routing | Hard |
| [DocumentArchivePipeline](Problems/DocumentArchivePipeline/) | C# 8 archive pipeline | Hard |
| [ConfigSnapshotMerger](Problems/ConfigSnapshotMerger/) | JsonNode config merge | Medium |

Each problem folder includes a **starter `.csproj`** and **`Program.cs`** with class shells and `// TODO:` stubs — implement the TODOs, then evaluate with that folder's `EVALUATION.md` in Cursor. Open `AdvancedCSharpFeatures.sln` to build all projects at once.

## Workflow

1. Read module tutorials (`02. C# & LINQ/08. Advanced C# Features/NN. Topic/`)
2. Work **[01. Scenarios.md](01.%20Scenarios.md)** and **[02. DebugReading.md](02.%20DebugReading.md)** — self-check answers
3. Pick a **Problems/{Name}/** folder — implement TODOs in `Program.cs` — AI review with **EVALUATION.md**
