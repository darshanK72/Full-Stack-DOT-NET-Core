## Answers

### Question 1

Use `System.Text.Json` with `[JsonPropertyName]`, `[JsonIgnore]`, and enum converters for JSON; use `XmlSerializer` with `[XmlElement]` / `[XmlRoot]` for XML on the same class. `[JsonIgnore]` keeps internal notes off JSON; XML can still include or omit fields via its own attributes. Serialize with `JsonSerializer.Serialize` / `Deserialize` and `XmlSerializer` respectively (ch01).

### Question 2

Missing JSON properties deserialize to `default` — nullable reference types become `null`, value types become 0/false. No exception for unknown/missing keys by default. Adding `string? Nickname` keeps v1 payloads valid (ch01 versioning).

### Question 3

Reflection reads `PropertyInfo`, `GetCustomAttribute<DisplayLabelAttribute>()`, and `ExportableAttribute` once per type so new product classes only need attributes — no exporter code change. Framework pattern used by serializers and ORMs (ch02).

### Question 4

`Activator.CreateInstance(type)` or `ConstructorInfo.Invoke`. Target needs a public parameterless constructor (or you must supply ctor args via reflection). `Type.GetType(name)` resolves assembly-qualified names (ch02).

### Question 5

Constructor parses pattern once; `Compiled` JITs for faster matching. Static `Regex.IsMatch` re-parses every call. Reuse avoids allocation and parse cost on hot paths (ch03).

### Question 6

Loop with `Match.NextMatch()` or enumerate `Matches`. Named group `(?<id>\d+)` exposes `Groups["id"]` without substring math on full `Value` (ch03).

### Question 7

`Regex.Replace(input, pattern, "[REDACTED]")`. Non-participating or unused capture groups still match but need not appear in replacement; use non-capturing `(?:...)` when captures are unnecessary (ch03).

### Question 8

`dynamic` binds at runtime via DLR — fast to write, fails at runtime with `RuntimeBinderException` on typos. Reflection is verbose but explicit; both lack compile-time checks. Strong `InventoryItem` catches errors at compile time (ch04).

### Question 9

`nameof(Sku)` renames safely with refactor tools and prevents typos vs magic strings. Evaluated at compile time to `"Sku"` (ch04).

### Question 10

Without `volatile`, CPU/JIT may cache the bool in a register; the worker may not see the main thread's write promptly. `volatile` forces reads/writes to memory for visibility (not mutual exclusion — use locks for compound operations) (ch04).

### Question 11

Tuple switch labels like `(OrderPriority.Critical, _)` and `(OrderPriority.Express, true)` document decision table in one construct; exhaustiveness checking and `_` default clarify fall-through (ch05).

### Question 12

`if (int.TryParse(text, out int qty))` declares `qty` in the `if` condition scope, eliminating a separate declaration line before the call (ch05 out variables).

### Question 13

`ref return` from a method like `ref Order FindById(...)`. Caller mutates through the ref alias. Throw `KeyNotFoundException` when id absent (ch05 ref returns).

### Question 14

Tuple deconstruction: `(int express, int standard) = router.CountByPriority(orders);` or `var (express, standard) = ...` (ch05 tuples).

### Question 15

`string Id` non-nullable default; `string? Notes` explicitly nullable. Dereferencing `Notes` without check yields CS8602 possible null reference (ch06 NRT).

### Question 16

Switch expression: `doc.Kind switch { DocumentKind.Text => "text/", ... }` is expression-valued, no break/drop-through bugs, concise (ch06).

### Question 17

Find last dot index `i`, slice `fileName[(i + 1)..]` or use `Path.GetExtension` in production; `^1` indexes from end for last character checks (ch06 indices/ranges).

### Question 18

Using declaration `using StreamWriter w = new(...);` disposes at end of enclosing scope (method), including on exception, without extra braces — syntactic sugar for try-finally dispose (ch06).

### Question 19

`_folderCache ??= new Dictionary<string, string>();` assigns only when left side is null (ch06 ??=).

### Question 20

`JsonNode.Parse` yields mutable tree; iterate patch properties and assign to base object nodes; read values with `root["key"]` without defining a DTO class (ch01 JsonNode).
