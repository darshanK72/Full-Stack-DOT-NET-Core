## Answers

### Question 1

**`"UserName"`** (PascalCase). `PropertyNamingPolicy = null` disables camelCase conversion; default serializes CLR property names (ch01 options).

### Question 2

**Runtime exception** when constructing `XmlSerializer` or on serialize: `Invoice` lacks public parameterless constructor. XmlSerializer requires public parameterless ctor and public read/write properties (ch01 XML requirements).

### Question 3

**`prop` is null.** Default `GetProperty` only returns public properties. Need `GetProperty("Cost", BindingFlags.NonPublic | BindingFlags.Instance)` (ch02 BindingFlags).

### Question 4

**Compile error CS0579** — duplicate attribute type where `AllowMultiple = false`. Second `[Tag("b")]` conflicts (ch02 AttributeUsage).

### Question 5

**Bug:** `Groups[1].NextMatch()` is wrong — `NextMatch()` is on `Match`, not `Group`. Second id never parsed correctly. Fix: `m = m.NextMatch()` then read `Groups[1]` (ch03).

### Question 6

**`ok` is true.** Non-greedy still matches one `A`. No bug on this input — illustrates greedy vs non-greedy behavior (ch03).

### Question 7

**RuntimeBinderException** at runtime — `Qty` was never set on dynamic object (ch04 dynamic).

### Question 8

Not a bug in snippet — **`nameof(StockKeepingUnit)`** updates with rename refactor; literal `"Sku"` becomes stale (ch04 nameof).

### Question 9

**Compile error CS0103** — `n` is in scope only inside the `if` block in older rules; in C# 7+ out var scope extends to end of method **when declared in out var in statement**. Actually in C# 7+, `out int n` in `if` is in scope for rest of block containing the if — **for `if` statement, scope is the enclosing block (method)** so this **compiles** and prints 42 twice. Wait - C# 7 out variable scope: for `if (TryParse(..., out int n))` the variable is in scope in the **else** and rest of the enclosing block. So it **compiles** in C# 7+ and prints 42 then 42. Let me verify...

From C# spec: out variable declared in if condition is in scope in the enclosing block (the method). So Question 9 compiles and outputs 42 twice. That's actually a teaching point about scope - not a bug.

I'll change the answer: **Compiles (C# 7+). Prints 42 twice** — out variable scope extends to end of enclosing block, which surprises developers expecting declaration-only-inside-if (ch05).

### Question 10

**Silent bug:** returns ref to `arr[0]` when id 99 missing, mutating wrong order. Should throw `KeyNotFoundException` instead of dummy ref (ch05 ref return).

### Question 11

**Compile error CS8506** — switch expression not exhaustive; missing `Binary` case and `_` default (ch06 switch expressions).

### Question 12

**Prints `.pdf`** (last 4 chars), not `pdf`. Correct slice: `name[(name.LastIndexOf('.') + 1)..]` (ch06 ranges).

### Question 13

**Compile warning CS8602** (nullable enable); if forced to run with null, **NullReferenceException** at runtime (ch06 NRT).

### Question 14

**NullReferenceException** — must initialize: `cache ??= new();` before indexer assign (ch06 ??=).

### Question 15

**InvalidOperationException** or format exception — JSON value is string `"30"`, not number; cannot `GetValue<int>()` directly. Parse string or use `GetValue<string>()` then TryParse (ch01 JsonNode).

### Question 16

**Deserializes successfully** with `Tier = 1` (enum numeric value). String enum names require `JsonStringEnumConverter` (ch01 enums).

### Question 17

**Not guaranteed** without `volatile` or `Interlocked` — worker may never observe `_stop == true` due to CPU caching. Use `volatile bool` or `Interlocked.Exchange` (ch04 volatile).

### Question 18

**NullReferenceException** at runtime on `x.Length`. Null-forgiving `!` suppresses compile warning only; does not change runtime behavior (ch06 NRT).
