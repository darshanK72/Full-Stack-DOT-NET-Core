## Build projects

| Problem | Domain | Difficulty |

| [PayrollProcessor](Problems/PayrollProcessor/) | Payroll & compensation | Hard |

Each problem folder includes a **starter `.csproj`** and **`Program.cs`** with class shells and `// TODO:` stubs — implement the TODOs, then evaluate with that folder's `EVALUATION.md` in Cursor. Open `ObjectOrientedProgramming.sln` to build all projects at once.

## Workflow

1. Read module tutorials (`02. C# & LINQ/02. Object Oriented Programming/NN. Topic/`)
2. Work **[01. Scenarios.md](01.%20Scenarios.md)** and **[02. DebugReading.md](02.%20DebugReading.md)** — self-check answers
3. Pick a **Problems/{Name}/** folder — build from zero in that folder — AI review with **EVALUATION.md**
