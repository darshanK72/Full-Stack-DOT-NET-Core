## Answers

### Question 1

CS7036 — missing `new`. Fix: `Patient p = new Patient();` (ch.01 `new` keyword).

### Question 2

Prints `50`. Reference types share one object (ch.01 instance vs reference).

### Question 3

CS0103 — `qty` should be `_qty` or use `this` keyword (ch.01 `this`).

### Question 4

CS0200 — init-only/get-only property cannot be assigned after construction (ch.02 read-only properties).

### Question 5

`IndexOutOfRangeException` at runtime (ch.02 indexers).

### Question 6

CS7036 — chained `: Employee(id)` requires a one-parameter constructor that does not exist. Add `Employee(int id) : this(id, "")` or chain to two-parameter ctor correctly (ch.03 constructor chaining).

### Question 7

CS0120 — instance field `Count` from static method. Fix: make `Count` static or make `Reset` instance (ch.04 static vs instance).

### Question 8

Prints `0`. Missing `override` on `Circle.Area`; hides base method instead (ch.05 overriding).

### Question 9

Prints `Staff`. `new` hides; reference typed as `Worker` calls base virtual unless override used (ch.05 method hiding vs polymorphism).

### Question 10

CS0144 — cannot instantiate abstract class (ch.06 abstract class).

### Question 11

CS0738 — return type must match interface (`byte[]` not `string`) (ch.06 interface implementation).

### Question 12

CS1061 — ambiguous `Code` on concrete type. Use cast: `((IA)item).Code` or `(item as IB).Code` (ch.06 explicit interface implementation).

### Question 13

CS0070 — event can only be invoked from declaring class; subscribers use `+=` only (ch.08 event keyword, events vs public delegate).

### Question 14

Callers can replace or invoke delegate without publisher control; events restrict to `+=`/`-=` from outside (ch.08 events vs delegates).

### Question 15

Wrong `EventArgs` type — pass `new SensorReadingEventArgs(value)` and declare `EventHandler<SensorReadingEventArgs>` (ch.08 EventHandler&lt;T&gt;, custom EventArgs).

### Question 16

Likely prints nothing / KeyNotFound — `Equals` overridden without matching `GetHashCode`; dictionary hash buckets break (ch.02 Equals/GetHashCode).

### Question 17

Prints `Order#42` (ch.02 override ToString).

### Question 18

No — finalizer runs nondeterministically when GC collects; not deterministic like `Dispose` (ch.03 destructor/finalizer; Finalize vs Dispose preview).

### Question 19

CS0712 — cannot instantiate static class (ch.04 static class rules).

### Question 20

CS0122 — `protected` not accessible from non-derived `Program` on `Base` instance. Same error for `private protected`; `protected internal` would allow access only from same assembly + derived types (ch.07 protected, protected internal, private protected).

### Question 21

Yes — both compile; prints `1000` and `0.05` (ch.04 const vs static readonly, ch.03 static constructor).

### Question 22

Prints `1`. Copy constructor clones values into new instance; independent objects (ch.03 copy constructor).
