## Answers

### Question 1
First line prints `1` (only 2). After adding 4, second prints `2` (2 and 4) — deferred query re-evaluates source (ch.01).

### Question 2
CS1061 — extension methods not found without `using System.Linq;` (ch.01).

### Question 3
Only **Priority** — second `OrderBy` replaces first. Need `ThenBy` for zone then priority (ch.03).

### Question 4
`InvalidOperationException` — sequence contains no elements (ch.02 Average on empty).

### Question 5
Equal counts. `Count(predicate)` short-circuits same as Where+Count but avoids building intermediate iterator — prefer `Count(pred)` (ch.02).

### Question 6
`InvalidCastException` on `42` — use `OfType<ProductRow>()` to skip (ch.10 Cast vs ch.02 OfType).

### Question 7
Skip/Take applied before sort — page slices arbitrary insertion order, then re-sorts only that page. Fix: `OrderBy` then `Skip` then `Take` (ch.11).

### Question 8
`true` — vacuous truth for `All` on empty (ch.09).

### Question 9
Prefer `Any()` — short-circuits at first element; `Count()` may enumerate entire sequence (ch.09).

### Question 10
`InvalidOperationException` — `First` with no match (ch.06).

### Question 11
`InvalidOperationException` — `Single` when more than one match (ch.06).

### Question 12
No — `Last(predicate)` returns last **in enumeration order** matching predicate, not max date. Use `OrderByDescending(DueDate).First()` (ch.06).

### Question 13
`ArgumentException` — duplicate key (ch.10 ToDictionary).

### Question 14
`InvalidOperationException` from `g.First()` on empty group — use `DefaultIfEmpty()` in left outer pattern (ch.05).

### Question 15
CS1943 — join key types must match exactly (ch.05).

### Question 16
No — `lineCount` is **3** (one IEnumerable per order). Need `SelectMany` for 6 lines (ch.08).

### Question 17
`10` — Range(1,10) yields ten values ending at 10 (ch.12).

### Question 18
`xy` — Repeat returns same reference three times; mutating one affects all (ch.12).

### Question 19
TakeWhile: **2** items (80, 75 — stops at 60). Where: **3** (80, 75, 90 — 60 breaks prefix only) (ch.11 TakeWhile vs ch.02 Where).

### Question 20
SequenceEqual prints `True`. Intersect Count is 3 — not a full equality test; order/duplicate semantics differ (ch.09 vs ch.07).

### Question 21
NullReferenceException or invalid cast — missing `<price>` element. Use `?.` or check null before cast (ch.13).

### Question 22
`InvalidCastException` or runtime error casting null attribute to bool — use `(string?)e.Attribute("active") == "true"` or null-safe pattern (ch.13).
