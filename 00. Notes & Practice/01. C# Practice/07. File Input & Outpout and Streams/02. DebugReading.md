## Answers

### Question 1
`IOException` — folder is not empty. Need `Directory.Delete("exports", recursive: true)` or delete files first.

### Question 2
`IOException` — sharing violation. The open `StreamWriter` holds an exclusive lock on Windows until disposed. Delete after `Dispose`, or use `using`.

### Question 3
Mojibake / garbled accented characters — UTF-8 bytes interpreted with the system ANSI code page.

### Question 4
Wrong read order corrupts parsing — first `ReadInt32` reads bytes from the length-prefixed string header, producing garbage `id`; subsequent `ReadString` misaligns. Often `EndOfStreamException` or nonsense values. Fix: read string then int to mirror write order.

### Question 5
`GetFullPath` resolves relative paths against `Environment.CurrentDirectory`, not the project or exe folder unless they coincide.

### Question 6
Prints `3` — split breaks inside `"Acme, Inc"`, yielding three tokens instead of two fields.

### Question 7
`/etc/hosts` — a rooted segment resets `Path.Combine` to that root (Unix absolute path).

### Question 8
Prints `0` (default byte) — `Read` returns 10 but does not zero the buffer; bytes 10–99 are uninitialized/default. Always use the return value and only interpret bytes 0..returnValue-1.

### Question 9
Prints `False` then `True` — `Move` removes the source path.

### Question 10
`FormatException` — in invariant culture, comma is a thousands separator, not decimal; `"12,99"` is not a valid decimal text for invariant parsing.

### Question 11
Zero additional lines — `ReadToEnd` consumed the stream; `EndOfStream` is already true.

### Question 12
`DirectoryNotFoundException` — `GetFiles` on a non-existent directory throws.

### Question 13
True — buffered writes may not be visible on disk until flush/dispose; `stream.Length` reflects logical stream position.

### Question 14
CS1061 — `TextReader` has no `EndOfStream`; that property exists on `StreamReader` only.

### Question 15
`FileNotFoundException`.

### Question 16
Reads from start of file, not end — need `stream.Seek(-2, SeekOrigin.End)` before `Read`.

### Question 17
Roughly `A`, newline, `B`, newline, then `C` appended directly after with no newline before `C` unless one was in the file — `AppendAllText` does not add a line break automatically.

### Question 18
Yes — `GetTempFileName()` creates a zero-byte file and returns its path.

### Question 19
`FileNotFoundException` — setting timestamps on a non-existent `FileInfo` path throws.

### Question 20
One line (`reset` only) — second writer uses default `append: false`, truncating/overwriting the file.
