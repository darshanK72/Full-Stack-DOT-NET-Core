## Answers

### Question 1

**CS1503** — cannot convert `string` to `int` for `Add`. Fix: `counts.Add(24);` — generics catch wrong type at compile time.

### Question 2

**InvalidCastException** at `(long)legacy[0]`. Boxed `int` unboxes only to `int`, not `long`. Fix: `(int)legacy[0]` or `(long)(int)legacy[0]`.

### Question 3

**KeyNotFoundException** on indexer GET for missing key. Safer: `if (stock.TryGetValue("WH-999", out int qty)) { … }`.

### Question 4

**ArgumentException** — duplicate key on second `Add`. To replace: `map["A"] = 2;` (indexer SET) or `Remove` then `Add`.

### Question 5

**InvalidOperationException** at runtime — no default comparer for `ShipmentItem`. Fix: implement `IComparable<ShipmentItem>`, or `Sort(comparer)`, or `Sort((a,b)=>…)`.

### Question 6

Prints **`1`**. Default `HashSet<string>` uses ordinal case-sensitive equality — `"LINQ"` and `"linq"` are distinct.

### Question 7

**InvalidOperationException** — queue empty. Use `TryDequeue(out string? next)` when empty is expected.

### Question 8

Prints **`20`** then **`10`** — LIFO: last pushed popped first.

### Question 9

**Alpha** then **Beta** — `SortedList` keeps keys sorted ascending regardless of insert order.

### Question 10

**NotSupportedException** — read-only view cannot mutate. Use `lanes.Add("C")` on the underlying list instead.

### Question 11

**Does not compile (CS0411 or CS1503)** — cannot infer single `T` for `int` and `string`; `T` must be one type for both parameters.

### Question 12

**CS0304** — `new T()` requires **`where T : new()`** constraint on the method (and `T` must have parameterless ctor). `CreateDefault<int>()` works with constraint; value types satisfy `new()`.

### Question 13

**InvalidOperationException** — collection modified during enumeration. Use `RemoveAll(n => n == 2)` or iterate a copy.

### Question 14

**Does not compile (CS0030 or CS0266)** — `List<string>` is not covariant to `List<object>`. `IEnumerable<string>` can assign to `IEnumerable<object>` (covariance), not `List<object>`.

### Question 15

Third line: **`ArgumentNullException`** on `Hashtable.Add(null, …)` — null keys not allowed. Lines 1–2 succeed (boxed int unbox to `int`).

### Question 16

Prints **`2`**. Default equality is reference equality — two different `Subscriber` instances both kept even with same email.

### Question 17

Prints **`Alpha`** — sorted ascending (`Alpha` before `zebra`).

### Question 18

Iterator body runs when **`Count()`** enumerates — lazy evaluation. `Evens()` alone only builds the enumerable object; no `yield return` executes until MoveNext.

### Question 19

**Count = 0**, **Capacity = 10**. Capacity hint pre-allocates backing array; Count is logical element count.

### Question 20

**ArgumentNullException** — `Dictionary<string,…>` rejects null keys on `TryGetValue`.
