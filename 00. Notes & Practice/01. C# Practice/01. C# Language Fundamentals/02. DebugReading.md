## Answers

### Question 1

CS0103 — missing `using System;` before namespace.

### Question 2

CS0029 string to char. Fix: `char grade = 'A';`

### Question 3

CS0029 char to string. Fix: `string code = "X";`

### Question 4

Integer division truncates. Fix: `return (decimal)totalCents / count;`

### Question 5

Cast applies after int division. Same fix — divide in decimal: `(decimal)totalCents / count`.

### Question 6

`attempts` is 0 (short-circuit `&&`).

### Question 7

`retries` is 0 (short-circuit `||`).

### Question 8

n=7, a=6, b=6.

### Question 9

Returns 5, c becomes 6. Should use `++c` to return 6.

### Question 10

CS0165 — unassigned local variable `x`.

### Question 11

CS0165 — `score` not assigned on all paths.

### Question 12

`3` then `3.5` (int division vs floating).

### Question 13

`70` then `90`.

### Question 14

display=`"Guest"`, nick=`"Guest"`.

### Question 15

text=null, isText=false (boxed int not string).

### Question 16

FormatException — should use TryParse and return false.

### Question 17

Double math before cast — use decimal literals/parameters for money.

### Question 18

false — flags is 3 (read+write), admin bit 4 not set.

### Question 19

`02` (skips i=1).

### Question 20

Yes — finally always runs.

### Question 21

Missing format specifiers / `:C` — use interpolation `$"{name} x{qty} @ {price:C}"`.

### Question 22

maxIdx=1 (first index with value 4).
