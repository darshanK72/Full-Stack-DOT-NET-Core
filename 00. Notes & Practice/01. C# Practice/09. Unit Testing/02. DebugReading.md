## Answers

### Question 1
**Compile error CS1069/CS0246:** `[Fact]` methods must be parameterless. Use `[Theory]` + data attributes for parameters.

### Question 2
**Compile error:** `[TestMethod]` and `Assert.AreEqual` require MSTest packages. Project has xUnit only — add MSTest or rewrite with `[Fact]` and `Assert.Equal`.

### Question 3
**No tests discovered / compile error:** `[Theory]` requires at least one `[InlineData]` or `[MemberData]`; otherwise no test cases generated.

### Question 4
**Verify fails:** SUT constructed with a different `Mock<IEmailSender>` than `emailMock`. Pass `emailMock.Object` into `ReservationService`.

### Question 5
**Runtime failure / theory mismatch:** Row has 2 values; method expects 3 parameters — row arity must match signature.

### Question 6
**Compile error CS0246:** `[ClassInitialize]` method must be `public static void` with `TestContext` parameter (MSTest signature).

### Question 7
**Zero tests discovered:** xUnit requires test classes to be `public`. `internal` class not visible to test SDK discovery (unless InternalsVisibleTo).

### Question 8
**Intermittent failure:** Static `_log` accumulates across tests; TestB expects count 2 only if A ran first in same process. Reset in constructor or use instance field; avoid static mutable state.

### Question 9
**Pass** if implementation correct: int literals convert to decimal; `ApplyDiscount(100m, 10m)` returns 90m; `Assert.Equal(90, result)` compares with numeric equality.

### Question 10
**TestsB not in collection:** Gets its own fixture instance (or fails injection) — not shared with A/C. Add `[Collection("SkuCatalog")]` to TestsB and ensure `ICollectionFixture<>` on definition class.

### Question 11
**Compile error:** `Assert.Throws` requires `Action`/`Func` lambda: `Assert.Throws<...>(() => calculator.GetLetterGrade(101))`.

### Question 12
**Verify fails (Times.Never effective):** Verify before Act — Capture not yet called. Always Act before Verify.

### Question 13
**Returns false:** More specific setup may override, but last registered Setup for matching expression typically wins; `It.IsAny` matches same call — last Setup Returns(false) applies → fraud declines.

### Question 14
**Cleanup still runs:** MSTest `[TestCleanup]` runs after each test even when Assert fails (unlike some misconceptions about aborted tests).

### Question 15
**Pass:** 100 * 6 = 600 ≥ 500 → bulk eligible true.

### Question 16
**Fail:** Assert expects 2 messages; successful booking sends exactly 1 — should `Assert.Single`.

### Question 17
**Error / no matching row:** `[DataRow]` supplies 2 values; method has 3 parameters — add expected decimal to each DataRow.

### Question 18
**Fixture not shared / compile or runtime issue:** `[CollectionDefinition]` must implement `ICollectionFixture<T>` to inject shared fixture into collection classes.
