## Question 1

A warehouse service must choose between standard and express shipping formulas at runtime based on a flag. The same method slot should hold whichever formula was selected when the order was placed. What language feature lets you store a callable algorithm in a variable and invoke it later?

## Question 2

## Question 4

## Question 5

## Answers

### Question 1

Store a method reference in a **delegate-typed variable** (custom or built-in). Invoke with `rule(args)` or `rule.Invoke(args)` at runtime (ch.01 delegates, method group conversion).

### Question 2

**Multicast delegates**: `handler += MethodA; handler += MethodB;` — one invoke runs all registered targets in order (ch.01 multicast `+=`).

### Question 3

**`-=`** removes the first matching target; if not found, the chain is unchanged (ch.01 multicast, Delegate.Remove equivalent).

### Question 4

**Null-conditional invoke**: `handler?.Invoke(args)` — skips when null (ch.01 null delegate checks; ch.05 `?.Invoke` on Func/Action).

### Question 5

**Delegate** for single callback/slot; **interface** when multiple related operations form a capability or DI contract (ch.01 delegates vs interfaces).

### Question 6

**Covariant return types** on delegates — method returning derived type satisfies delegate promising base return type (ch.01 covariance preview).

### Question 7

**Target-typed lambda** — compiler infers delegate type from parameter `PriceFilter` (ch.02 target-typed lambdas, custom delegate assignment).

### Question 8

**Expression lambda** for one-liners; **statement/block lambda** when locals, branches, or multiple steps needed (ch.02 expression vs statement).

### Question 9

**Method group conversion**: pass `RoundToNearestDollar` without `()` — compiler wraps as delegate (ch.02 method group vs lambda).

### Question 10

**Omitted parameter list** on anonymous method when body ignores delegate parameters; explicit list required when body uses parameters (ch.03 anonymous methods, omitted vs explicit params).

### Question 11

Replace with **lambda** `o => o.Total > 0`; **capture semantics identical** (ch.03 vs ch.02; deep dive ch.06 closures).

### Question 12

**Static class**, **static method**, **`this` on first parameter** only (ch.04 extension method rules).

### Question 13

Missing **`using` for the namespace** containing the static extension class — extensions are not found via the extended type's namespace (ch.04 namespace/using requirements).

### Question 14

The **instance method on `string` wins** — extensions never override existing instance API (ch.04 precedence).

### Question 15

**Func** requires a return value matching the last type parameter; void methods use **Action** (ch.05 Func vs Action).

### Question 16

Different **delegate types** — no implicit conversion; wrap at call site: `list.FindAll(p => func(p))` or method group on `.Invoke` (ch.05 Predicate vs Func&lt;T,bool&gt;).

### Question 17

**Func&lt;decimal&gt;** — zero parameters, `decimal` is the sole type arg = return type (ch.05 Func&lt;TResult&gt;).

### Question 18

**0.25m** — capture shares live storage, not snapshot at creation (ch.06 capture semantics; preview ch.02).

### Question 19

Prints **`3 3 3`** (shared loop variable). Fix: `int copy = i;` inside loop and capture `copy`, or pass `i` into a helper parameter (ch.06 for-loop pitfall).

### Question 20

Captured local is promoted to a **heap display class** field; returned delegate holds reference — local outlives stack frame (ch.06 closure lifetime).

### Question 21

**total is 15**; both lambdas share **one** captured field for `total` (ch.06 mutating shared capture).

### Question 22

Delegate is a **GC root** keeping display class and buffer alive until handler released — **unsubscribe / null delegate** (ch.06 memory/GC).

### Question 23

Yes — chained left-to-right. Static form: `StringExtensions.Truncate(StringExtensions.ToDisplayLabel(label), 20)` (ch.04 chaining).

### Question 24

**Parameter type at call site** — `Predicate<decimal>` vs `PriceTransform` vs `Func<decimal,decimal>` disambiguates overload; lambda must match chosen parameter (ch.02 target typing + ch.05 Func).
