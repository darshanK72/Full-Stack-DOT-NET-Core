## Answers

### Question 1

Yes — **method group conversion** assigns `StandardRate` to `ShippingRule` (ch.01).

### Question 2

Prints **`10`** — both handlers run, but on a returning multicast delegate only the **last** handler's return value is kept; both `DoubleValue(5)` return 10 (ch.01 multicast return rule).

### Question 3

**NullReferenceException** — null delegate invoked without `?.` (ch.01).

### Question 4

Prints **`50`** — first handler `5+1` return discarded; last handler `5*10` → 50 (ch.01 multicast return rule).

### Question 5

**CS1662** — lambda return type `int` from `p * 2` does not match **decimal** delegate return (ch.02).

### Question 6

**CS0834** — block with expression statement is not a valid expression lambda; use `=> p * 1.1m` or `{ return p * 1.1m; }` (ch.02).

### Question 7

**NullReferenceException** when accessing `o.LineCount` if `o` is null (ch.03 anonymous method body).

### Question 8

**CS1061** — extension not in scope; missing `using` for extension namespace (ch.04).

### Question 9

**CS1106** — extension method must be in **static class** (ch.04).

### Question 10

No — extension receives **null** as first arg; method handles it → **true** (ch.04 null receiver).

### Question 11

**CS0123** — `void` method cannot satisfy `Func<int,int>` (ch.05 use Action not Func).

### Question 12

First line yes; second **CS0123** or delegate conversion error — **Predicate** and **Func<int,bool>** are different types (ch.05).

### Question 13

Prints type name like **`System.Func`1[System.Decimal]`** — printing delegate shows type, not return value (ch.05 invoke requires `rate()`).

### Question 14

Prints **`1`** — removes 2 and 3 (ch.05 RemoveAll + Predicate).

### Question 15

Prints **False** — capture reads live `threshold` (40m); `45m <= 40m` is false (ch.06).

### Question 16

Prints **`333`** — classic for-loop shared `i` bug (ch.06).

### Question 17

Prints **`2`** — shared capture mutated twice (ch.06).

### Question 18

Prints **`3`** — 1+2 from same closure state (ch.06 factory counter).

### Question 19

**Two lines** — Combine multicast runs both (ch.01 Combine).

### Question 20

**NullReferenceException** — use `?.Invoke` (ch.05 null checks).

### Question 21

Prints **`abc`** — foreach per-iteration capture safe on modern C# (ch.06 foreach C# 5+).

### Question 22

**CS1106** — extension methods must be in **static** class (ch.04).
