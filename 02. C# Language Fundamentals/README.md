# 01. C# & LINQ — Curriculum Index

This folder is the **C# language and LINQ** track of the Full Stack .NET Core learning repository.

## How to use this curriculum

Every **module** has a `README.md` with a chapter list. Each **chapter folder** contains a reading tutorial (`Program.cs` or module entry files) scoped by the **folder name**.

| File | Purpose |
|------|---------|
| `README.md` (module) | Chapter list, prerequisites, module goals |
| `Program.cs` (chapter) | Reading-based tutorial — scope = folder name |

When creating or editing a tutorial chapter, follow **`@reading-tutorial`**: teach every important concept for that folder name with full context (sections, tables, runnable code, quick reference).
