# 00. .NET Framework Architecture

Conceptual and platform foundations **before and alongside** C# syntax. These chapters explain how computers run programs, what .NET is, and how C# code becomes running software.

> **Note:** This module focuses on **understanding the platform**. Runnable C# demos appear where they clarify execution (e.g. viewing IL, inspecting assemblies). Pure theory chapters may use markdown-only content until a demo adds value.

## Prerequisites

None — start here if you are new to programming or .NET.
